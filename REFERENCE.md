# Tools Reference

Tools and references I use with Claude Code, Pi, and opencode. The README covers what this repo ships; this file catalogs what I use from outside it.

## Claude Code plugins (external)

- **Vibe Log CLI**: https://github.com/vibe-log/vibe-log-cli
- **Handy Computer**: https://handy.computer
- **Basic Memory**: markdown-based memory (https://github.com/basicmachines-co/basic-memory)
- **Episodic Memory**: session memory across projects (https://github.com/obra/episodic-memory)
- **Claude Code Viewer**: a viewer for Claude Code sessions (https://github.com/d-kimuson/claude-code-viewer)
- **Recall**: recall from past sessions (https://github.com/zippoxer/recall)

## Pi extensions (external)

### Transcription
- **pi-transcribe**: speech-to-text for local audio/video (https://github.com/earendil-works/pi-transcribe)

### Terminal & status
- **pi-tab-status**: tab status in the terminal title (https://github.com/tmustier/pi-extensions/tree/main/tab-status)
- **pi-usage-extension**: usage/token stats (https://github.com/tmustier/pi-extensions/tree/main/usage-extension)
- **pi-powerline-footer**: powerline-style status footer (https://github.com/nicobailon/pi-powerline-footer)
- **pi-rewind-hook**: a rewind hook for pi (https://github.com/nicobailon/pi-rewind-hook)

### Capture & workflow
- **pi-interactive-shell**: run interactive CLIs (TUIs, auth flows) in overlays (https://github.com/nicobailon/pi-interactive-shell)
- **threads**: conversation threads for pi (https://github.com/laulauland/dotfiles/tree/main/shared/.pi/agent/extensions/threads)

### MCP
- **pi-mcp-adapter**: MCP server adapter for pi (https://github.com/nicobailon/pi-mcp-adapter)

## MCP servers

- **Exa**: web search and research (https://docs.exa.ai/reference/exa-mcp)
- **Deepwiki**: GitHub repo documentation Q&A (https://docs.devin.ai/work-with-devin/deepwiki-mcp)
- **Grep**: search a million GitHub repositories (https://vercel.com/blog/grep-a-million-github-repositories-via-mcp)
- **mcpdoc**: docs via llms.txt and context7 (https://github.com/langchain-ai/mcpdoc)
- **FastMCP**: framework for building MCP servers (https://gofastmcp.com/getting-started/welcome#mcp-server)
